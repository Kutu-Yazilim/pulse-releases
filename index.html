Explicit macOS permissions and a bundled read-only MCP server.

Pulse asks only for the permissions required by the features you turn on, stores your knowledge vault in plain Markdown on your disk, and ships pulse-mcp inside the app bundle so Claude Desktop, Claude Code, and Cursor can query your vault safely.

macOS Permission Why Pulse Uses It
Keychain Access Reads your Claude Code sign-in to display live subscription usage limits. Click Always Allow once so macOS does not prompt on every refresh.
Full Disk Access Lets Knowledge 2 read local Apple Mail and Messages databases on your Mac, and lets Cleaner measure developer caches accurately.
Calendar & Reminders Includes your -7 to +31 day schedule and due items in nightly Knowledge 2 Brief cards.
Accessibility & Screen Recording Powers Double Tap (Right Cmd ×2) inline reply insertion, custom HUD replacement, and per-task Operator actions.
Privileged Helper (Admin Prompt) Installed once from Settings to kill root processes, purge inactive RAM, and wake the Mac at 03:00 for nightly learning.

Connect Claude Code & Cursor via pulse-mcp

Pulse bundles a read-only Model Context Protocol server at /Applications/Pulse.app/Contents/MacOS/pulse-mcp. It exposes pulse://knowledge/index plus search, status, and brief tools—and cannot edit files or run shell commands. 

{
  "mcpServers": {
    "pulse-knowledge": {
      "command": "/Applications/Pulse.app/Contents/MacOS/pulse-mcp"
    }
  }
}
First Launch on macOS 26: Because Pulse is distributed directly outside the Mac App Store, right-click Pulse.app → Open (or approve in System Settings › Privacy & Security › Open Anyway) on first launch. Subsequent updates install automatically via Sparkle.
